# Python Learning
Мой учебный репозиторий для изучения Python и практики программирования.
Здесь находятся конспекты, упражнения, эксперименты с Python и небольшие учебные проекты.
## 🎯 Цели
* Уверенно освоить Python
* Понять ООП не только на уровне синтаксиса, но и на уровне устройства языка
* Научиться правильно организовывать код по модулям и пакетам
* Научиться писать полноценные проекты
* Освоить инструменты разработки и экосистему Python
* Постепенно перейти к разработке прикладных проектов

## 🧠 Принцип обучения

Основной подход:

> Сначала понять, как и почему это работает, затем использовать на практике.

При изучении новых возможностей Python стараюсь:

1. Разобраться в механике работы.
2. Написать реализацию самостоятельно.
3. Решить практическую задачу.
4. Проверить и исправить код.
5. Зафиксировать важные моменты в конспекте.
6. Использовать изученное в следующих проектах.
